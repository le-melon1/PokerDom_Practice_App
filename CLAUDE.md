# PokerDom Practice App

## Что уже сделано
- Реализован локальный тренажёр покера с FastAPI-бэкендом и веб-интерфейсом.
- Поддерживаются игровые раздачи, действие ботов, live EV-панель, dossier по сессии, история раздач и оценка решений тренером.
- Добавлен удобный запускатель проекта через `run_app.py` для запуска из любой директории.
- Добавлен регрессионный тест на запускатель проекта.

## Цели проекта
- Практиковать принятие решений в покере против ботов, обученных на реальных данных.
- Иметь живую оценку EV и GTO-рекомендации прямо во время раздачи.
- Сохранить состояние сессии и истории между перезапусками сервера.

## Основные проблемы и нюансы
- Проект локальный и однопользовательский, поэтому состояние хранится простым способом на диск.
- EV и solver-оценки являются практическими и приближёнными, а не полной no-limit solve.
- Важны тонкости правил покера: blind rotation, order of actions, side pots, all-ins, turnover ботов.
- Для стабильного запуска используется проектный виртуальный env и отдельный launcher.

## Как запускать
```bash
python3 run_app.py
```

Открыть в браузере:
- http://127.0.0.1:8001/
